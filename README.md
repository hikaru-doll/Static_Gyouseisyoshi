 ## 制作内容
- デザイン・コーディング 
- レスポンシブ対応
- スクロールに連動するアニメーションを JavaScript（Intersection Observer API） で実装
- アクセシビリティを意識したマークアップ
## 工夫したこと
トップページは、ユーザーが欲しいと思われる情報の優先順にレイアウトを組みました。  
背景色に落ち着きのある色を、フォントは全体の雰囲気に合う明朝体を採用しました。  
問い合わせのフォームには外部サービスのFormzuを使用しました。
掲載画像は『O-DAN』、人物画像は『いらすとや』で提供されている素材を使用し、画像容量の大きいものは表示の高速化を考慮してWebP形式へ変換しています。
